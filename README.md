# Bin Duty (Clean Vite + React + Tailwind)

This is a clean project scaffold that composes your uploaded **BinDuty** component inside a thin `App.jsx`.

## Stack
- React 18 + Vite (JS only)
- Tailwind CSS 3

## Setup (Windows or macOS/Linux)
1. Install Node 18+.
2. In this folder, run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the local URL from the terminal.

## Your Component
- Kept intact at: `src/components/BinDuty.jsx`
- Rendered from: `src/App.jsx`

## Print Card
Use the **Print 12 Weeks** button in the UI to print the quarter-page card.

## Deploy
- Push this to your Git repo (e.g., GitHub) and connect to Vercel.
- Default build command: `npm run build`
- Output directory: `dist`
